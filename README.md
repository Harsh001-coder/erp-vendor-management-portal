# ERP Vendor Management Portal

A modern ERP-based Vendor Management Portal built using React.js and Tailwind CSS.  
This project includes Admin and Vendor modules with onboarding workflows, purchase orders, invoice management, shipment tracking, payment tracking, barcode generation, and responsive dashboards.
